# FileStack

Self-made messy stack of document folders for RulesHorror.
Replaces the purchased `BrutalistLevelKit` `SM_File_Pocket7` (`/Game/Assets/BrutalistLevelKit/Models/Props/Items/SM_File_Pocket7`), which cannot be pushed to the public repository.

## Files

- `create_file_stack_blend.py`: generates the texture, the `.blend` and the FBX. Run it again after changing it.
- `FileStack.blend`: Blender source. The scene contains only `SM_FileStack`.
- `Exports/SM_FileStack.fbx`: FBX for Unreal import.
- `Textures/T_FileStack_Paper.png`: procedural paper atlas (1024², generated by the script, no readable text).

Regenerate without opening Blender:

```
"C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background --factory-startup --python create_file_stack_blend.py
```

## Geometry

- Size: `0.574 x 0.425 x 0.168 m`, same bounds as the original (Unreal cm min `(-29.0, -19.8, 0.0)`, max `(28.4, 22.7, 16.8)`); the stack is fitted to those bounds at the end of the script.
- Pivot: bottom of the stack (`z = 0`), same footprint position as the original. `Z` up.
- Facing: the open folder edges with papers sticking out face Unreal `+Y` (Blender `-Y`) and `+X`; folder spines are on the Unreal `-Y` side.
- Parts: 12 layers, bottom to top: thick dark green folder, green / blue-grey folders (two covers, paper block, spine, front cover edges drooping over the papers) alternating with loose paper bundles, loose sheets poking out at the front and sides, a manila folder with a printed form sheet on top. Small random rotations/offsets (fixed seed).
- About 2,000 triangles.
- UVs: boards use box projection (1 UV unit = 1 m); paper parts use real UVs into the atlas `T_FileStack_Paper`:
  - `u 0.0-0.5`: stacked sheet edges (paper block sides),
  - `u 0.5-1.0, v 0.5-1.0`: printed form page (grey dash "text", heading bar, boxes), top sheet only,
  - `u 0.5-1.0, v 0.0-0.5`: plain aged paper (sheet faces).

## Material slots

| Slot | Unreal material |
|---|---|
| `Folder_Board_Green` | opaque instance of `M_Prop_Base`, BaseColor `(0.040, 0.085, 0.062)`, Roughness `0.75` |
| `Folder_Board_Grey` | opaque instance of `M_Prop_Base`, BaseColor `(0.105, 0.130, 0.150)`, Roughness `0.70` |
| `Folder_Board_Manila` | opaque instance of `M_Prop_Base`, BaseColor `(0.420, 0.340, 0.215)`, Roughness `0.80` |
| `Paper_Stack` | textured instance (`M_Prop_Textured`) with `T_FileStack_Paper`, tint `(1, 1, 1)`, Roughness `0.85` |

`GrimeAmount` about `0.3-0.35` on all slots (world-space dirt that darkens the color and raises roughness slightly).

## Unreal

- Asset: `/Game/Objects/FileStack/SM_FileStack` (Nanite off, 1 convex hull collision).
- Replaces `SM_File_Pocket7`, used in `L_Lobby`.
- Import settings: FBX exported with forward `-Z`, up `Y`, unit scale applied. Blender `+X` arrives as Unreal `+X`, Blender `+Y` as Unreal `-Y`.
