# Booklets

Self-made open stapled booklet and folded newspaper for RulesHorror.
Replaces purchased `Deko_MatrixDemo` meshes, which cannot be pushed to the public repository:

| New mesh | Replaces |
|---|---|
| `SM_BookletOpen` | `/Game/Assets/Deko_MatrixDemo/Apartment/Meshes/SM_BooksPamphlets_G01_N1` |
| `SM_NewspaperFlat` | `/Game/Assets/Deko_MatrixDemo/Apartment/Meshes/SM_BooksPamphlets_I01_N1` |

## Files

- `create_booklets_blend.py`: generates both textures, the `.blend` and the FBX files. Run it again after changing it.
- `Booklets.blend`: Blender source. The scene contains only `SM_BookletOpen` and `SM_NewspaperFlat` (both at the origin, overlapping).
- `Exports/SM_BookletOpen.fbx`, `Exports/SM_NewspaperFlat.fbx`: FBX files for Unreal import.
- `Textures/T_Booklet_Pages.png`, `Textures/T_Newspaper_Folded.png`: procedural atlases (1024², generated by the script, no readable text, no real names or logos).

Regenerate without opening Blender:

```
"C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background --factory-startup --python create_booklets_blend.py
```

## Geometry

### SM_BookletOpen

- Size: `0.21 x 0.296 x 0.017 m`, same bounds as the original (Unreal cm min `(-10.5, -14.8, 0.0)`, max `(10.5, 14.8, 1.7)`).
- Pivot: floor under the spine center. `Z` up. Spine along `X`; page tops point to `+X`; the left page of the spread is on Unreal `-Y`.
- Parts: thin cover card under both halves, two page blocks (thin at the gutter, bulging next to it, outer edges springing up so the booklet rests on its spine), two staples in the gutter.
- About 1,100 triangles.
- UVs: real UVs into `T_Booklet_Pages`: `v 0.291-1.0` the printed spread (headers, paragraphs of grey dashes, a bar chart, a table, page-number marks, gutter shadow); below it, plain cover card (left) and stacked page edges (right).

### SM_NewspaperFlat

- Size: `0.379 x 0.187 x 0.011 m`, same bounds as the original (Unreal cm min `(-19.7, -9.3, 0.0)`, max `(18.2, 9.4, 1.1)`).
- Pivot: floor under the center. `Z` up. Text reads along `+X`; masthead toward Unreal `-Y` (open edges); the rounded fold faces Unreal `+Y`.
- Parts: one closed folded body extruded along `X` (rounded fold edge, slightly bowed top, top sheet lifting at the open edge, gentle waviness).
- About 700 triangles.
- UVs: real UVs into `T_Newspaper_Folded`: upper half = front page above the fold (masthead made of block shapes, dark headline bars, two grainy street-scene photo rectangles, columns of dashes); lower left = back page columns (underside); lower right = stacked sheet edges (open edge and cut ends).

| `SM_NewspaperFlat` | `Newspaper_Print` | textured instance (`M_Prop_Textured`) with `T_Newspaper_Folded`, tint `(1, 1, 1)`, Roughness `0.9`, GrimeAmount `0.25` |

## Unreal

- Assets: `/Game/Objects/Booklets/SM_BookletOpen`, `/Game/Objects/Booklets/SM_NewspaperFlat` (Nanite off, 1 box collision each).
- Replace `SM_BooksPamphlets_G01_N1` and `SM_BooksPamphlets_I01_N1`, used in `L_Office`.
- Import settings: FBX exported with forward `-Z`, up `Y`, unit scale applied. Blender `+X` arrives as Unreal `+X`, Blender `+Y` as Unreal `-Y`.
