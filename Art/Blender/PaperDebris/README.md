# PaperDebris

Self-made loose paper sheets lying on the floor, for RulesHorror.
Replaces the purchased `BrutalistLevelKit` debris meshes, which cannot be pushed to the public repository:

| New mesh | Replaces |
|---|---|
| `SM_PaperDebris_A` | `/Game/Assets/BrutalistLevelKit/Models/Props/Debris/SM_Debris_Paper_Set1` |
| `SM_PaperDebris_B` | `/Game/Assets/BrutalistLevelKit/Models/Props/Debris/SM_Debris_Paper_Set5` |
| `SM_PaperDebris_C` | `/Game/Assets/BrutalistLevelKit/Models/Props/Debris/SM_Debris_Paper_Set6` |

## Files

- `create_paper_debris_blend.py`: generates the texture, the `.blend` and the FBX files. Run it again after changing it.
- `PaperDebris.blend`: Blender source. The scene contains only the three meshes (all at the origin, overlapping).
- `Exports/SM_PaperDebris_A.fbx`, `Exports/SM_PaperDebris_B.fbx`, `Exports/SM_PaperDebris_C.fbx`: FBX files for Unreal import.
- `Textures/T_PaperDebris_Printed.png`: procedural paper atlas (1024², generated by the script, no readable text).

Regenerate without opening Blender:

```
"C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background --factory-startup --python create_paper_debris_blend.py
```

## Geometry

- Bounds (Unreal cm), same as the originals:
  - `SM_PaperDebris_A`: min `(-34.8, -24.8, -0.2)`, max `(37.2, 32.2, 5.0)`, 6 sheets, about 2,100 triangles.
  - `SM_PaperDebris_B`: min `(-33.5, -17.9, 0.2)`, max `(29.4, 29.6, 2.3)`, 3 sheets (one lying apart), about 1,000 triangles.
  - `SM_PaperDebris_C`: min `(-17.9, -19.8, 0.0)`, max `(32.6, 26.1, 3.2)`, 3 sheets, about 1,000 triangles.
- Pivot: floor level under the pile, same as the originals. `Z` up. No particular front.
- Each sheet is an A4 page (`0.21 x 0.297 m`) built as a thin closed slab (`0.3 mm`, 7 x 10 grid), so no two-sided material is needed.
  Sheets are bent with simple height functions (arched, curled edges, lifted corners, a bent-up flap, soft wrinkles).
  Upper sheets are automatically lifted `1.6 mm` above the sheets under them and drape off their edges, so overlapping sheets never intersect.
- The script fits the sheet positions to the original XY bounds and scales the bend heights to the original Z bounds.
- UVs: real UVs into the atlas `T_PaperDebris_Printed`:
  - `v 0.293-1.0`: two printed A4 pages side by side (report page with title bar, paragraphs of grey dashes and a table; form page with letterhead box, field lines, checkboxes and a table),
  - `v 0.0-0.293`: plain aged paper (back sides, sheet edges, and sheets lying blank side up).

## Material slots

| Slot | Unreal material |
|---|---|
| `Paper_Printed` | textured instance (`M_Prop_Textured`) with `T_PaperDebris_Printed`, tint `(1, 1, 1)`, Roughness `0.85`, GrimeAmount `0.4` |

## Unreal

- Assets: `/Game/Objects/PaperDebris/SM_PaperDebris_A`, `/Game/Objects/PaperDebris/SM_PaperDebris_B`, `/Game/Objects/PaperDebris/SM_PaperDebris_C` (Nanite off, no collision needed).
- Replace `SM_Debris_Paper_Set1`, `Set5`, `Set6`, used in `L_Lobby`.
- Import settings: FBX exported with forward `-Z`, up `Y`, unit scale applied. Blender `+X` arrives as Unreal `+X`, Blender `+Y` as Unreal `-Y`.
