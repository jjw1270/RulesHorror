## 반영 내용

- 별도 클래스 설계도 슬라이드를 제거하고, StoryFlow / Custom UI / Item Core 기능 슬라이드에 각각 설계도 이미지를 통합했습니다.
- 설계도는 PPT 도형이 아니라 Mermaid/Kroki 렌더링 PNG로 교체했습니다.
- 핵심 코드도 텍스트 박스가 아닌 코드 캡처형 PNG로 배치했습니다.
- 핵심 코드 슬라이드는 평가성 문구 대신 실제 실행 흐름만 남겼습니다.
  - `StartResolvedScene`: Start / Resume 지점 해석 및 EntryLink 진입
  - `MoveToLink`: Shot / Branch / Scene 링크 라우팅
  - `EvaluateBranch`: Branch Template 복제, 결과 Pin 선택, 다음 Link 실행
- `구현 경계`, `구현 근거` 메모성 문구는 제거했습니다.

- 기존 텍스트 코드 박스보다 읽히도록 실제 흐름만 남겼습니다.
